# BeautyCare Acessível — Back-End + UI
Pacote de execução dos artefatos da atividade.

- `api/`: FastAPI + SQLite + SQLAlchemy + Pydantic
- `ui/`: React + Vite consumindo a API
- `documentacao/Plano_Sprints.md`: tecnologias, comandos e tarefas das sprints

O pacote é um MVP acadêmico. Não afirma criação de repositório remoto real: o usuário deve criar o GitHub/GitLab e substituir `URL_DO_REPOSITORIO` pelo endereço real.
